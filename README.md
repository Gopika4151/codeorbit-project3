# 📸 AI Image Classification Using a Pretrained Model

## 📌 Project Overview
AI Image Classification is a web-based application developed using HTML, CSS, JavaScript, TensorFlow.js, and the MobileNet pretrained model.

Users can upload an image, and the application analyses it using the pretrained AI model to identify objects and display predicted labels with confidence scores.

This project was developed as part of the CodeOrbit Tech Artificial Intelligence Internship.

## 🎯 Objective
To build an image classification application using a pretrained deep learning model that identifies objects in uploaded images.

- Visual Studio Code

## ✨ Features
- Upload images from a device

## ⚙️ How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Ensure an active internet connection.
4. Open `index.html` using Live Server.
5. Wait for the MobileNet model to load.
6. Click the Choose Image button.
7. Upload an image from your device.
8. Click Classify Image.
9. View the predicted labels and confidence scores.

## 🧠 Working Principle
1. The user uploads an image.
2. The application displays the image preview.
3. The MobileNet pretrained model analyses the image.
4. The model extracts important image features.
5. The model predicts possible object categories.
6. The application displays the top 5 predictions with confidence scores.

## 🤖 Pretrained Model – MobileNet
MobileNet is a lightweight pretrained deep learning model used for image classification.

It is designed to recognize different objects in images while using fewer computational resources than many larger image classification models.

TensorFlow.js allows the model to run directly in a web browser.
